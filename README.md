# Hai提词器

<p align="center"><strong>让讲稿跟着你走，而不是让你追着稿子读。</strong></p>

Hai提词器是一款面向 macOS 的轻量悬浮提词器。它通过语音跟读识别朗读进度，自动推进稿件，让录课、视频口播、线上分享和演示表达更自然。

> 当前状态：`0.3` 内测版。本仓库用于公开产品方案、版本进展和用户反馈，不包含产品源码。

## 它解决什么问题

传统提词器通常按固定速度滚动。讲快了，稿子跟不上；讲慢了，稿子又提前跑走。演讲者需要不断分心控制滚动，视线也容易明显偏离镜头。

Hai提词器希望把控制关系反过来：

1. 你自然朗读，不必迁就固定滚动速度。
2. 系统识别当前读到的词，按顺序推进稿件。
3. 当前内容尽量保持在提词窗第二行附近。
4. 已读内容变灰，未读内容保持白色。
5. 中途从其他段落重新开始时，系统尝试重新定位。

## 适用场景

- 录制知识分享、课程和视频号口播
- 在线会议、直播和远程培训
- 对着摄像头完成演讲或产品介绍
- 一边播放 PPT，一边查看自己的讲稿
- 需要多次修改、重复使用讲稿的内容创作者

## 当前能力

- AI 语音跟读，按词识别朗读进度
- 顺序朗读优先，重新定位为低优先级
- 提词窗自动滚动，也支持手动滚动
- 已读文字变灰，未读文字保持白色
- 字号、背景透明度和窗口大小调节
- 提词窗保持在普通窗口上方
- 录屏隐藏开关
- 本地历史文本记录、恢复和删除
- 简洁中文界面

## 基本使用流程

1. 在主窗口粘贴讲稿。
2. 点击“打开提词窗”。
3. 把悬浮窗移动到摄像头附近。
4. 调整字号、窗口大小和背景透明度。
5. 点击“开始跟读”，允许麦克风和语音识别权限。
6. 按自己的节奏朗读，观察文字是否随进度自动推进。

## 隐私原则

- 不要求注册账号。
- 不包含广告或用户分析 SDK。
- 稿件历史只保存在当前 Mac。
- 可以删除单条历史记录或清空全部记录。
- 麦克风仅在开启跟读时使用。
- 语音识别由 macOS 系统能力提供。

详细说明见 [PRIVACY.md](PRIVACY.md)。

## 当前边界

- PowerPoint 等软件的独占全屏放映模式可能限制第三方悬浮窗显示，窗口化放映通常更稳定。
- “录屏隐藏”依赖 macOS 和录屏软件的窗口共享策略，不同组合下表现可能不同。
- 当前主要针对普通话和中文讲稿优化。
- 重新定位和高噪声环境下的识别稳定性仍在持续改进。
- 当前版本尚未完成 Apple 开发者签名与公证，GitHub Releases 中的安装包仅用于内测。
